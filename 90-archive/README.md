# 보관

현재 empty: 보관·폐기 처리한 옛 자료는 없다.
바이트 동일본도 원래 노트북 목록에 보존하며 여기로 옮기거나 삭제하지 않았다.
허브가 보관 범위를 정한 후에만 자료를 등록한다.

상태: empty / indexed.
진입: 현재는 진입 불필요; 보관 대상으로 확정된 자료가 등록된 뒤
이탈: [상위 색인](../README.md)으로 돌아간다.
키워드: 보관, 폐기이력, 옛버전. [메타](meta.yaml).
