# 디자인 원본

현재 empty: 아이콘·폰트·시안 파일을 별도 보관하지 않는다.
노트북의 Windows 폰트 문자열은 시스템 폰트 참조이며 이 폴더의 자료가 아니다.
디자인 원본이 추가되기 전에는 상위 에셋 색인으로 돌아간다.
