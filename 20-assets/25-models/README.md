# 모델·가중치

현재 empty: 별도 학습 모델·가중치 파일이나 외부 보존 링크가 없다.
노트북 학습 결과를 이 구획에 새로 내보내지 않았다.
가중치가 등록되기 전에는 상위 에셋 색인으로 돌아간다.

상태: empty / indexed.
진입: 현재는 진입 불필요; 재사용할 모델·가중치가 등록된 뒤
이탈: [상위 색인](../README.md)으로 돌아간다.
키워드: 가중치, 학습모델, 외부저장, 체크포인트. [메타](meta.yaml).
