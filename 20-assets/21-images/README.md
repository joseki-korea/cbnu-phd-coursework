# 이미지

현재 empty: 별도로 등록한 원본·가공 이미지는 없다.
노트북 안의 셀 출력·그림은 원래 노트북에 보존했다.
독립 이미지가 추가되기 전에는 상위 에셋 색인으로 돌아간다.

상태: empty / indexed.
진입: 현재는 진입 불필요; 별도 원본·가공 이미지가 등록된 뒤
이탈: [상위 색인](../README.md)으로 돌아간다.
키워드: 이미지원본, 가공이미지, 셀출력, 별도자료없음. [메타](meta.yaml).
