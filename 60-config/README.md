# 설정

현재 empty: 환경 예시·애플리케이션·배포 설정이 없다.
비밀값이나 자동 실행 설정을 추가하지 않았다.
설정 파일이 필요해질 때만 이 구획에 등록한다.

상태: empty / indexed.
진입: 현재는 진입 불필요; 환경 예시·도구 설정이 등록된 뒤
이탈: [상위 색인](../README.md)으로 돌아간다.
키워드: 환경예시, 설정, 비밀값제외. [메타](meta.yaml).
