# 레포 구획 시범 인수인계

목표: 작은 독립 실습 저장소에서 14구획·검색 길잡이·원문 이동을 실제 브랜치로 검증한다.
범위: 기존 노트북 13개와 표준 구획·문서 링크이며 부모 저장소 경로는 유지한다.
결정: 원문은 10-source, 문서·인수인계·검증·버전 노트는 각각 해당 구획에 한 번 보관한다.

[이관 계획](../30-docs/2026-11-28--repo-layout--plan.md)과
[파일 manifest](../30-docs/2026-11-28--repo-layout--manifest.json)를 먼저 확인한다.
노트북 내용 변경·자동 실행 설정·배포 작업은 포함하지 않는다.
원래 위치의 파일이 필요하면 manifest의 old/new 매핑으로 새 위치를 찾는다.
다음 일: PR 독립 검수 → 허브의 병합 판단 → 작은 독립 레포별 후속 배정이다.
