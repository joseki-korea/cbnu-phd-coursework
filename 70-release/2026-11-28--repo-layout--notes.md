# 레포 구획 시범 변경 노트

실습 진입점이 루트의 파일 나열에서 README → 10-source의 주제별 목록으로 바뀐다.
기존 노트북 13개의 내용·파일명은 그대로이며 경로 앞에 10-source/가 붙는다.
각 표준 구획은 README·meta.yaml로 보유 자료와 진입/이탈 조건을 안내한다.

[실습 목록](../10-source/README.md) · [이관 계획](../30-docs/2026-11-28--repo-layout--plan.md)
실행 가능한 앱·배포 산출물이 생기는 변경은 아니다. 학습 실행 결과를 새로 검증한 기록도 아니다.
