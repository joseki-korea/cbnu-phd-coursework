# 변경 보고

폴더 이관으로 달라진 실습 진입 경로와 보완 범위를 요약한다.
경로 변경 보고는 허용 kind인 report 파일로 보관한다.
배포·학습 실행 산출물이 생긴 변경을 의미하지 않는다.

상태: populated / indexed.
진입: 경로 변경의 사용자 영향과 이번 PR의 범위를 빠르게 확인할 때
이탈: [상위 색인](../README.md)으로 돌아간다.
키워드: 변경보고, 경로변경, 진입점, PR2. [메타](meta.yaml).
